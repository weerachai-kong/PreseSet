สรุปข้อเสนอโครงการ (Project Charter Summary) : PaceSet

1. ข้อมูลทั่วไปโครงการ (Project Overview)

- ชื่อโครงการ: PaceSet
- แนวคิดหลัก: Mobile Web Application หรือในอนาคตทำเป็น Application ลง play store สำหรับช่วยควบคุมเวลาและจังหวะการออกกำลังกาย (Pacing) รองรับทั้งการฝึกแบบสลับเวลา (Interval) และการนับรอบ/เซ็ต (Reps & Sets) พร้อมระบบแสดงภาพประกอบท่าทาง
 สามารถเซ็ตวันในแต่ละโปรแกรมการออกกำลังกายได้เช่น
    A{
    - 1 คนมีได้หลายโปรแกรม
    - ใน 1 วันจะเลือกใช้โปรแกรมไหนบ้าง
    }
    1 คนมี A ได้หลายชุด
- เป้าหมายหลัก: พัฒนา Full-Stack Web Application ด้วย TypeScript ทั้งระบบ เพื่อฝึกฝนทักษะการใช้งาน Next.js, Nest.js, PostgreSQL และ Firebase Cloud Storage

3. ฟีเจอร์หลักของระบบ (Key Core Features)
    1 Dual-Mode Workout Engine:
    • Interval Mode: จับเวลาสลับช่วงออกกำลังกายและช่วงพัก (เช่น วิ่งเร็ว 15 วินาที / เดิน 5 วินาที) ต่อเนื่องจนครบเวลา
    • Reps & Sets Mode: กำหนดจำนวนครั้งและเซ็ต (เช่น สควอท 7 รอบ x 4 เซ็ต) พร้อมนาฬิกานับถอยหลังช่วงพักเซ็ต
    2 Visual Exercise Guidance:
    • แสดงภาพประกอบและคำแนะนำท่าทางการออกกำลังกายที่ถูกต้อง โดยดึงไฟล์จาก Firebase Storage
    3 Mobile-Optimized Experience:
    • ใช้ Screen Wake Lock API ป้องกันหน้าจอดับขณะจับเวลา
    • มีเสียงสัญญาณเตือน (Audio Beeps) เมื่อถึงเวลาสลับช่วง
    4 Custom Program Management:
    • สร้าง ปรับแต่ง และบันทึกตารางการออกกำลังกายส่วนตัวลงในฐานข้อมูล PostgreSQL
    5 Hydration Reminder (แจ้งเตือนกินน้ำ):
    • แจ้งเตือนตามช่วงเวลาทั้งวัน (เช่น ทุก 1–2 ชม.) ขณะเปิดแอปอยู่ ผ่าน Browser Notification API
    • ตั้งค่าเปิด/ปิด และเลือกช่วงเวลาได้ใน Profile / Settings
    6 Internationalization (i18n):
    • สลับภาษา Thai / English ทั้ง UI

4. ทักษะที่จะได้รับจากการทำโปรเจกต์นี้ (Technical Learning Outcomes)
    • Full-Stack TypeScript Mastery: การเขียน TypeScript แบบ End-to-End ทั้ง Client-side และ Server-side พร้อมการแชร์ Data Interfaces
    • Relational Database Design: การออกแบบ Schema และการใช้ Prisma ORM จัดการ Migration บน PostgreSQL
    • Clean Architecture: การวางโครงสร้าง Backend API ด้วย Modular Architecture และ Dependency Injection ตามมาตรฐาน Nest.js
    • Hybrid Cloud Integration: การเชื่อมต่อระบบ Custom Backend ร่วมกับบริการ Third-party Cloud Storage (Firebase)

5. ผู้ใช้และการยืนยันตัวตน (User & Auth)
    • Role: ผู้ใช้ทั่วไปเท่านั้น (ยังไม่มี Admin UI ใน MVP)
    • Auth: สมัคร / เข้าสู่ระบบด้วย Email + Password
    • Profile: ชื่อที่แสดง, อีเมล, ตั้งค่าเสียงสัญญาณเตือน (เปิด/ปิด), ตั้งค่าแจ้งเตือนกินน้ำ, สลับภาษา TH/EN, Logout

6. แผนผังหน้าจอและ User Flow (Screen Map)
    หน้าจอหลัก:
    1) Splash / Welcome (Canva: ไม่ใช้ช่อง password — จำกัดใน Canva AI Code)
    2) Home / Today
    3) Programs List
    4) Create / Edit Program
    5) Day Schedule
    6) Active Workout — Interval Mode
    7) Active Workout — Reps & Sets Mode
    8) Workout Complete / Summary
    9) History
    10) Profile / Settings

    Flow สั้น ๆ:
    Splash/Welcome → Home → (Programs | Day Schedule | History | Profile)
    Programs → Create/Edit Program
    Home หรือ Day Schedule → Active Workout (Interval หรือ Reps & Sets) → Summary → History

7. โมเดลข้อมูลสรุป (Data Model Overview)
    • User: id, email, passwordHash, displayName, beepEnabled, locale (th|en), waterReminderEnabled, waterReminderIntervalMinutes
      + audit: create_date, create_by, update_date, update_by, is_delete
    • Program / ExerciseStep / ProgramDay / WorkoutSession: เช่นเดียวกันมี audit + soft delete (is_delete)
    • Query ดึงเฉพาะ field ที่ใช้ผ่าน Prisma `select` (ไม่ดึงทั้งแถวแบบ SELECT *)

8. ขอบเขต MVP (MVP Scope)
    รวมใน v1:
    • Dual-Mode Workout Engine (Interval + Reps & Sets)
    • Visual Exercise Guidance (รูปจาก Firebase Storage)
    • Screen Wake Lock + Audio Beeps
    • CRUD Program + Day Schedule
    • Auth Email/Password + Profile พื้นฐาน
    • History / Summary หลังจบเซสชัน
    • i18n Thai / English
    • Hydration Reminder (Browser Notification ตามช่วงเวลา ทั้งวัน ตอนเปิดแอป)
    ลำดับพัฒนาปัจจุบัน: Frontend (prese-set-fn) + Backend (prese-set-bn) — ต่อ API เข้า Next.js ต่อไป
    โครงสร้างโปรเจกต์:
    • prese-set-fn = Next.js Frontend
    • prese-set-bn = Nest.js Backend (Prisma + PostgreSQL, พอร์ต 3001, prefix /api)
    นอก MVP (อนาคต):
    • Native Application ลง Play Store
    • Admin UI สำหรับจัดการ media library รวมศูนย์
    • Social / sharing / coach mode
    • Push notification นอกแท็บ (Service Worker / background)
